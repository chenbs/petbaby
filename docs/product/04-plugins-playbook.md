## 1. 状态流转规则

```
idea（弹药库） → testing（当周小红书测款中） → live（已上架小程序） → archived（归档）
```

- idea → testing：由每周一复盘决定，同时最多 2 个方向在测。
- testing → live：测试笔记互动/私信/成交跑赢基准（当前 live 玩法的均值）。
- testing → archived：两周内数据不及基准的 50%。
- live → archived：连续 4 周付费单数为个位数且无流量贡献。
- 归档玩法保留记录，节日/热点可复活重测。

本文的 `live` 表示当前代码和正式产品导航可见，不代表微信小程序已经通过审核或真实 Provider 已完成联调；发布状态以 `../operations/05-release-checklist.md` 为准。

## 2. 首发玩法详细规格（阶段 1 上线）

> 以下三节是**阶段一的原始首发规格**，保留作设计意图记录。三处定价已被后续改造修正（PL-01 转免费、PL-03 转分档），当前值见 `15-功能入口清单.md` 第四章。

### PL-01 宠物证件系列 ｜ layout ｜ 原 9.9 元，**现免费带水印**

- 内容：身份证、护照、户口本、疫苗接种证（一套 4 款，先做身份证）。
- 输入：1 张正脸照 + 档案字段（名字、物种、生日、性别）。
- 生成：证件版式模板 + LLM 生成"签发机关/备注"彩蛋文案（如"发证机关：猫猫管理局"）。
- 输出：单张高清图（可 4 款打包 19.9）。
- 卖点：小红书验证过的爆款品类；出图 10 秒；晒图率极高。

### PL-02 宠物电影海报 ｜ layout ｜ 12.9 元

- 输入：1-3 张照片 + 档案字段。
- 生成：电影海报版式（3 种风格：好莱坞大片/文艺片/港片）+ LLM 生成片名、tagline、"影评人短评"。
- 输出：竖版海报高清图。
- 卖点：即"image-2 炫酷海报"方向的零成本实现；文案是笑点来源，分享动机强。

### PL-03 宠物时光画册 ｜ layout ｜ 原 12.9 元，**现 19.9 起按积累量分档**

- 输入：6-20 张照片 + 档案字段；主题：成长/生日/治愈日常/节日。
- 生成：封面 + 标题 + 每页配文（宠物口吻/主人口吻可选）+ 固定版式。
- 输出：手机长图 + PDF。
- 卖点：情感浓度最高的基本款；是纪念册（PL-20）和实体画册（阶段 3）的底座。
