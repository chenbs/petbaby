# 宠物趣味测试：首期内容与实现记录

## 公开内容观察（2026-09-28）

- [16Personalities 中文首页](https://www.16personalities.com/ch) 用易记的类型承接答题，并围绕特点与关系继续解释；其首页也提供分享预览图。借鉴的是结果分层和分享结构，不使用其分类或措辞。
- [Arealme 动物人格测验](https://www.arealme.com/animal/zh/) 公开页面展示了明确的题量、类型名称、特点、相处方式与社交预览图。首期测试压缩到每份 10 题，并将观察对象改为宠物的日常表现。
- 访问了小红书“宠物 MBTI”和抖音“宠物 MBTI”的公开搜索页；内容由客户端动态加载，当前环境无法可靠获取条目、互动量或排名。因此不据此宣称某主题“热门”或复制具体内容。

## 首期四份测试

| 测试 | 观察重点 | 结果方向 |
| --- | --- | --- |
| 它的隐藏性格 | 宠物面对新鲜事、陌生人和日常节奏的反应 | 社交小太阳、安静侦探、黏人棉花糖、认真小队长 |
| 它带来的小小好运 | 一起生活时容易发现的好事与轻松时刻 | 日常拾光师、惊喜接球手、人缘召集官、安稳守护星 |
| 你们的陪伴关系 | 主人与宠物相处的距离、分工和默契 | 并肩搭子、小尾巴同盟、互相照顾组、默契室友 |
| 它的情绪充电方式 | 宠物如何带来笑意、安静、勇气和仪式感 | 快乐启动键、慢充小暖炉、勇气补给站、仪式感制造机 |

四份测试各 10 题，每题三个生活场景选项。选项分别给主类型和次类型计分；同分时用主类型选择次数及稳定的答案摘要排序。同样的选择始终得到同一结果，不进行真实运势预测。所有题目和结果均为原创娱乐内容，不构成动物行为诊断、财务或其他现实决策建议。

新增测试只需在 `apps/platform/src/domain/fun-tests.ts` 注册题目、结果和展示信息，小程序从公开 API 获取同一份内容；无需新增答题页面或计分代码。已保存的结果保留当时的结果文案快照，后续更新题库不会改写旧分享。
