# 官网视觉与功能重构需求

## 目标

在保留现有官网整体排版骨架、首屏视频、导航与主要 CTA 的基础上，采用「品牌影棚」方向重做图片展示与功能表达，让访客第一眼感受到：产品成熟、宠物可爱、有趣且值得马上打开小程序尝试。

## 需求

### 1. 视觉方向与布局

- 采用 B「品牌影棚」方向：浅色背景、墨色文字、少量品牌玫红、细边界、大留白和产品画廊感。
- 保留现有首屏视频展示、首屏结构、导航、区块顺序和 CTA 路径。
- 首屏之后的核心作品使用更大的主视觉；减少小卡、缩略带和装饰性道具，让成品占据主要视觉面积。
- 图片比例、裁切、留白和标签建立统一规则，桌面、平板、手机三档都要保持可读。

### 2. 图片资产

- 现有官网图片全部退出首页展示，不继续沿用木桌、胶带、相框、纸张等旧素材。
- 重新生成一套官网专用图片，画面需要同时满足：趣味性强、可爱感明显、宠物表情和动作有记忆点、用户看完想立刻给自己的宠物试一次。
- 视觉应保持企业级完成度：构图干净、主体突出、色彩明快但不廉价、细节稳定、无文字乱码、无水印、无品牌 logo、无不必要的人物或道具。
- 图片类型覆盖：玩法主视觉、AI 创意/「如果我是人」示例、互动页、短片、成长记录、纪念空间和社交分享头像/辅助图。
- 新图片先生成并检查，再接入官网；不覆盖旧素材，保留可回滚能力。

### 3. 功能展示重组

官网产品介绍必须以 `docs/product/21-小程序功能点清单.md` 为事实来源，不再只展示「图文 / AI 肖像 / 视频」三类概念。首页按访客理解组织为以下功能组，并明确对应小程序能力：

1. **宠物档案与照片库**：宠物档案、默认宠物、陪伴天数、照片九宫格、照片预览与管理（MP-07、MP-08）。
2. **图文作品**：宠物身份证、电影海报、时光画册等玩法货架与制作流程（MP-01、MP-02）。
3. **AI 创意工坊**：模板货架、宠物身份照、普通模板四选一、作品保存与分享（MP-12、MP-13）。
4. **如果我是人**：独立展示宠物人化入口；说明它是把宠物特征转译为自然的人类角色，生成两张候选供选择，具体可用模板以小程序上线内容为准（MP-12.3～MP-13.9）。
5. **互动页面与短片**：互动场景、点按收集星尘、公开分享、15 秒导出，以及 10/20/30 秒陪伴短片、字幕、音乐和渲染（MP-14～MP-17）。
6. **成长记录**：按年份整理照片、里程碑、成长时间线和年度短片入口（MP-10）。
7. **健康助手**：症状分流、体重、免疫/驱虫记录、提醒、健康档案 PDF 和历史记录；官网只能写「辅助记录与分流」，不能写诊断、治疗或处方（MP-11）。
8. **纪念空间**：纪念时间线、纪念册、纪念视频、星尘页和分享（MP-18、MP-19）。
9. **会员、年度报告与实体纪念品**：会员权益、年度报告、高清解锁和实体纪念品履约（MP-20、MP-21）。

首页不需要罗列页面编号，但每个功能组必须能在视觉或文案上被识别，且不得超出小程序当前实际能力。健康功能遵守分流不诊断原则；「如果我是人」不得暗示人宠合影或主人身份卡链路。

### 4. 首屏文案

首屏改为第一人称叙事，保留「记录陪伴」的核心含义，采用以下润色方向：

- 标题：**把我留在你的记忆里**（在「把我留在」后换行）。
- 副文案：**我不是只有今天在陪你 / 那些一起度过的平常一天，也值得被好好记住 / 打开小程序，把我最爱你的样子留下来陪你**（每句单独起行，不带句号）。
- 首屏按钮：**微信扫码**，右侧保留小程序码，删除码旁重复的「扫码打开小程序」说明。

移动端允许句内自然折行，但不得回到「它陪你」的第三人称口吻。CTA 继续表达打开小程序开始创作，不承诺尚未开放的服务、价格或效果。

## 验收标准

- 首页不再引用旧的 `play-*`、`detail-*`、`work-*`、`style-*` 图片作为展示图。
- 首屏视频地址与展示容器保持不变，改为自动完整播放并循环；首屏标题和副文案为第一人称版本。
- 首页至少覆盖上述 9 个功能组，并包含「如果我是人」独立入口。
- 新图片无文字乱码、无水印、无明显畸形，且在 1440px、768px、390px 下主体完整可见。
- `apps/website` 的 `astro check`、构建和现有官网验证脚本通过。
