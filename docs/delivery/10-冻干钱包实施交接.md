## 0. 一句话口径（不要改）

- 站内货币叫 **冻干**，量词 **颗**。1 元 = 1 颗（不含加送）。
- **先扣冻干，再执行任务**：
  - 没有预览，也没有「免费生成、付费解锁」。产物入库就是正式版（`works.locked=false`）。
  - **没有免费重拍，也没有用户手动重试**。「再拍一张」等于新建任务、重新扣费，原结果保留。
  - 任务失败时，系统自动重试 2 次（共 3 次尝试）。仍失败就**全额退还冻干**，只退回余额，**不退现金**。
  - 「效果不满意退款」取消。
- **免费玩法**（证件照 `pet-id-card`、成长对比 `pl-23`）每天限 10 次。
- **颗数**：

| 玩法 | 颗数 |
| --- | --- |
| AI 单张 · 写真 | 2 |
| AI 单张 · 如果我是人 | 3 |
| AI 单张 · 人宠 | 4 |
| 写真套餐 10 张 / 20 张 | 12 / 20（单张失败按张退 1 颗；套餐档位已从 10/36 改为 10/20） |
| 电影海报 | 2 |
| 画册（按积累量分档） | 18 / 28 / 38 |
| 短片 / 年度短片（按积累量分档） | 15 / 22 / 30 |
| 纪念短片 | 26 |
| 纪念册（纪念空间、纪念阶段的画册） | 免费 |
| 年度报告 | 18 |
| 健康档案 PDF | 6 |
| 年度健康记录 | 6 |

  **颗数唯一来源是 `apps/platform/src/domain/dongan-pricing.ts`**，端上一律读接口，不写死。
- **充值**：
  - 新人首充：6 元得 12 颗，每账号一次。
  - 普通档：6/18/38/68/128 元，分别到账 6/22/50/95/188 颗。
  - 单日充值累计不超过 300 元。
- **新人礼**：添加第一只宠物后送 3 颗，7 天有效。按微信 openid 去重。
- **会员**：年度会员及全部权益已下线。数据表保留，套餐全部置 `archived`。
- **Web 端**不上线（D6），只需能编译、E2E 能跑。注销账户不处理余额（D7）。
- **实体商品**仍收现金、走普通微信支付，去掉了会员九折。

## 5. 坑（已踩过的）

- **换行符混用**：部分源文件是 CRLF（例如 `platform-service.ts`）。用脚本按字符串替换时，要先把 `\r\n` 归一成 `\n`，写回时再还原，否则会静默匹配不上。
- **任务重试会延后**：失败后自动重试会把 `available_at` 推迟 2 秒，视频推迟 5 秒。测试里要先 `UPDATE ... SET available_at=now()` 再跑 worker。
- **测试余额**：建档会自动发 3 颗新人礼；其余测试用 `fundWallet` 充值。不充值时付费玩法一律 402。
- **扣费与入队必须同事务**：扣费和写入任务在同一个 `inTransaction` 里，才能保证余额不足时任务不落库。新增扣费点必须沿用这个写法。
- **validate 第 3 项**：`.wxss` 禁止写死颜色和 `rgba(`。颜色只能进 `theme/themes/*.js` 的 `skin`，再用 build-skin-css 同步到 `app.wxss`。
- **不属于本任务的改动**：工作区里混有另一个并行任务（艺术写真 v14 素材）的改动，包括 `plugins/registry.ts`、`plugins/runtime.ts`、`domain/pet-art-photo.ts`、`pages/index/index.wxml|wxss`、`scripts/build-sample-assets.js`、`assets/samples/**`、`tools/imagegen/**`、`publish-art-v14-assets.mjs`。**不要回滚，也不要混进本任务的提交。**
- **AI 记账成本**：`AI_IMAGE_COST` 默认 0.08；商业测算按 0.15 算，两者不必一致。
