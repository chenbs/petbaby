1 设计方向板：橘子汽水（默认主题）

默认主题改为「橘子汽水」：奶油暖底配墨蓝色文字，按钮用浅一档的橘子色 #FF9A52 加墨蓝字（不用白字），点缀色是奶黄和钴蓝。橘色给人阳光、零食、晒太阳的暖意，墨蓝让画面精致而不显幼稚。莓果色不再使用。另外 3 套主题见 themes.html。对比度按 WCAG 公式用 node 计算。

2 首页：宠物名片 → 人类转生计划 → 麻麻精选 → 分类瀑布流

按 2026-09-30 的代码，首页从上到下依次是：宠物大图、全宽「开始记录」按钮、麻麻精选（车窗封面、9 款横滑、6 套写真横滑）、人类转生计划（8 张人像横滑）、「今天想做点什么」自动轮播（画册和电影海报）、按心情挑玩法（10 个分类卡）、最近收好的照片、今日里程碑、去年今日、趣测、作品玩法（写真、短片、成长对比、证件）。一共 11 个同级区块，首屏只能看到宠物。改版不删内容，只调整层级：两个运营重点（人类转生计划、麻麻精选）放到第一、二屏，其余内容收进分类瀑布流和「今日一格」。

7 关键路径对比：新用户拿到第一张创作图

点击次数按当前代码的页面跳转推算（假设已有宠物档案），不是埋点数据；改版后的数字是设计目标。

当前 · 有照片 首页→滚 1.5 屏找到分类卡→横滑选效果→下拉框确认宠物→选身份照→生成→静态等待约 1 分钟→选候选→解锁（点击前看不到价格）
当前 · 无照片 …选效果→空状态「去上传照片」→离开到照片库→记录模式上传→手动返回并重新找到效果→…
改版 首页首屏「人类转生计划」→效果页（宠物与最近照片已预选，可就地拍照 / 上传）→开始→等待，可离开，好了提醒→选中 · 按钮上带价格 · 可分享

目标：有照片时从约 7 次点击降到 3 次；无照片时不离开当前页。
