# 小程序玩法效果图交付计划

## 范围与判定

只处理当前打包在 `apps/miniprogram/assets/samples/` 与 `assets/fun-tests/` 的玩法效果展示图。宠物照片、用户作品、主题预览图、图标及其他图片不在本次范围内。

首页代码实际引用的图留在包内：7 张玩法入口图、15 张模板封面、4 张写真场景、1 张趣味测试封面、1 张黑白水墨肖像专用横版封面，共 28 张。只在其他页面出现的 94 张图转为远程读取。同一张图同时出现在首页和详情页时只保留一份本地文件。

## 实施步骤

1. 依据当前素材清单和首页入口 ID，从项目保留的原图导出宽、高均为现用尺寸约 1.5 倍的 JPEG。合成样片在目标尺寸重新渲染文字与画面，不放大已有小图。
2. 首页图写入 `assets/home-effects/`，趣味测试首页封面保留在 `assets/fun-tests/personality.jpg`。其他图暂存于 `apps/platform/.data/miniprogram-effects/remote/`，以内容哈希命名，建立图片尺寸、字节数和 SHA-256 清单。
3. 使用最小权限 COS 凭据上传远程图，逐张匿名回读并验证原始对象 ETag、图片格式和尺寸。静态样片使用 `babykitty-static-one-1252454114`（`ap-shanghai`，公有读、私有写），客户端通过该桶的 HTTPS 域名直接加载。业务私有桶、用户照片和生成母版不参与迁移。
4. 云端全部验证通过后，更新小程序素材清单，排除旧本地样片目录及非首页趣味测试封面，再验证首页、写真、模板、电影、画册、互动与趣味测试页面。
5. 执行 `npm run validate`，用开发者工具实际预览，核对总包体小于 2 MB，并检查至少一张远程图的真机加载。
