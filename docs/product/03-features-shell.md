## P0 功能（阶段 1 上线必备）

### F1 登录与账户

- 微信一键登录（小程序 openid），不做手机号强制绑定（支付前也不需要）。
- H5 分享页访客无需登录；访客点"我也做一个"跳转小程序。
- 验收：新用户从打开到进入玩法 ≤ 2 步。

### F2 宠物档案（极简版）

- 字段：名字（必填）、物种猫/狗/其他（必填）、性别、生日或到家日（选填但引导填写）、头像 1 张。
- 支持多宠（列表管理），首个档案创建 ≤ 30 秒。
- 作用：为 LLM 文案提供人称/称谓；生日字段是阶段 3 召回钩子；档案是长期资产的锚点。
- 验收：档案字段可被任意插件通过 profile_fields 声明引用。

### F3 照片上传

- 单次 1-20 张（由插件的 input.photos 决定），客户端压缩后上传 OSS。
- 低清晰度照片给出提示（影响实体印刷的在下单时二次提示）。
- 上传的照片归入该宠物的照片库，可在其他玩法中复用（不必重复上传）。
- 验收：10 张照片在 4G 网络下上传 ≤ 30 秒；照片库按宠物聚合可勾选复用。

### F4 生成任务框架（插件运行时）

- 统一任务流：创建任务 → 排队 → 调用对应生成器（html-template / image-api / h5-theme）→ 产出 → 通知。
- 任务表轮询即可，无需消息队列；前端展示排队位次和预计时间。
- 失败自动重试 1 次，仍失败则退还额度/退款并提示。
- 新玩法通过插件描述文件注册，**上架不发版**（模板与配置热更新；小程序端仅渲染通用流程）。
- 验收：新增一个 html-template 玩法从模板完成到线上可用 ≤ 2 小时（不含审核）。

### F5 免费额度与防刷

- 免费额度：每天 1 次低清带水印生成，全玩法共享。
- image-api 类玩法免费层用低价模型或限额更严（每天全站总额度封顶，超出提示明日再来）。
- 防刷：同 openid 限频、生成任务排队、图片尺寸上限、异常调用告警。
- 验收：单日 API 成本超过阈值自动熔断降级。

### F6 支付与订单

- 微信支付（个体工商户），单次解锁模式；订单表记录玩法、金额、状态。
- 退款规则（写死在支付页）：生成失败全额退；效果不满意退 50%（每用户限 1 次）。
- 验收：支付到解锁高清 ≤ 5 秒；退款可在后台一键操作。

### F7 作品库

- 我的作品列表：按宠物/玩法筛选，可重新编辑（换文案、换照片顺序）、重新分享、补付解锁。
- 作品保留策略：免费用户低清作品保留 90 天（成本控制），付费作品永久。
- 验收：编辑后重新生成不重复扣额度（同一作品 24h 内）。

### F8 H5 分享页

- 每个作品可生成分享链接（默认仅链接可见，可关闭）+ 分享长图（带水印与小程序码）。
- 页面结构：作品展示区 + 宠物名片 + 固定底部 CTA"给我的宠物也做一个"（直达同款玩法）。
- h5-theme 类作品：分享页即体验页，内置录屏视频生成/下载按钮。
- 验收：分享页首屏加载 ≤ 2 秒（CDN）；CTA 点击率可埋点统计。

### F9 埋点与数据看板

- 唯一漏斗：访问 → 选玩法 → 建档 → 上传完成 → 生成成功 → 预览 → 付费 → 分享 → 分享页访问 → 分享页 CTA 点击。
- 每个事件带玩法 id，支撑赛马机制的按玩法对比。
- 实现：小程序自带分析 + 自建单张事件表 + 一个查询脚本/简易页面，不搭数据平台。
- 验收：周一复盘所需的全部指标（见 operations/01 第 5 节）可在 10 分钟内取出。
