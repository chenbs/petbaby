# 验收文档

版本：v1.0 ｜ 日期：2026-08-03
性质：**可执行验收清单**。每条给出验证方法与通过标准，逐条打标 `PASS` / `FAIL` / `BLOCKED`。
上游：`17-产品改造方案.md`（产品口径）、`18-技术实现方案.md`（技术落点）

## 用法

- 每项在「结果」列打标。`FAIL` 必须修复后重验；`BLOCKED` 必须写明阻塞原因与依赖。
- **验收顺序按批次**：门禁（G）→ 上线阻塞（V1）→ 结构性（V2）→ 清理（V3）→ 回归（R）。
- 前一批未全绿不进入下一批。
- 标注「⚠️ 外部环境」的项在开发机无法完成，需在测试机或有对应依赖的环境验证，不计入本轮完成度但必须登记。

### 验收发现的三个缺陷（均已修复）

这三条都是**只有真跑才能发现**的，读代码看不出来：

1. **删除 manifest 会让历史纪念作品彻底打不开。** 产品改造方案 4.1 写「历史作品靠 `plugin_snapshot` 打开」——**这个前提是错的**：`works` 表没有这一列（只有 `generation_tasks` 和 `orders` 有），`hydrateWork` 一律 `getRuntimePlugin(work.pluginId)` 现查。删掉 PL-20/21/22 后，所有历史纪念册/纪念视频/纪念页会抛 `WORK_INCOMPLETE`，**打不开也删不掉**。
   **修复**：老 manifest 保留为 `status: "archived"` 而非删除。`/api/plugins` 只输出 live，所以新用户看不到；`createGeneration` 要求 live，所以不能用它建新任务；而历史作品读得出。
2. **纪念册按 19.9 而不是 49 收费。** `hydrateWork` 没有解析调性，而 `createOrder` 的基础价取自 `work.plugin.pricing.unlockPrice` —— 纪念形态的定价在 `toneVariants` 里，不解析就拿到画册的基础价。
   **修复**：`hydrateWork` 内按宠物生命阶段解析调性。
3. **体重记录的日期全是错的。** `date` 列被驱动交回 JS `Date` 对象，`String(value).slice(0, 10)` 得到 `"Sat Aug 01"` 而不是 `"2026-08-01"`。体重曲线的每一个横坐标都会是这种字符串。
   **修复**：新增 `asDateString`，Date 分支取本地年月日（不用 `toISOString()`，`date` 列无时区，转 UTC 会在东八区退回前一天）。

另外顺带修掉四处：AI 候选的**免费预览此前也没有标识**（预览从原始字节缩）；`pet-id-card-bundle` 四证套餐随 PL-01 转免费而失效已下线；免费作品会拿到比付费更干净的图（`locked=false` 时 `getDownload` 返回 `outputKey`，而水印原先只叠在预览上）；`payGrowthOrder` 的 `monthlyQuota` 在新权益下得 NULL 而列是 NOT NULL。
