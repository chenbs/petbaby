提示词与验收标准见 [`docs/product/24-宠物小岛素材清单.md`](../../../../docs/product/24-宠物小岛素材清单.md)（**以第 7.4 节的表为准**）。

## 生成顺序（不要一次生 7 张）

**第一轮 `pet-sample.png` —— 已完成，抠图风险已解除。**
它原本是唯一有技术风险的一张（柔和边缘 + 品红抠图可能留毛边或啃掉耳朵绒毛）。
实测结论：**可行**，前景残留品红 0.07%、叠草地无色环、白胸兜与耳内绒毛完整。
有描边反而比无描边更好抠 —— 闭合轮廓线就是最好的抠图边界。实测数据见 `24` 号文 6.1。

## 三条硬要求

1. **`scene-yard.jpg` 里不能有任何动物。** 宠物是运行时叠上去的图层，底图里画了猫会变成两只。
2. **透明底优先用工具直接输出的 alpha PNG**；不支持时才用纯品红 `#FF00FF` 背景。
   不要用白底 —— 摩奇是橘白猫，白底会把白胸兜一起抠掉。
   **当前模型不支持直出透明**（`background=transparent` 返回 400
   `Transparent background is not supported for this model`），`generate.mjs` 会自动回落品红并打印提示，
   这是预期路径不是故障。
3. ~~**品红背景必须是纯色**，放大看四角是同一色值~~ —— **这条判据过严，已废止**（`24` 号文 6.1）。
   实测四角必然有轻微差异（编码环节在极端像素上的振铃），但背景主体干净、抠图无毛边。
   按四角严格判定会把可用的图全部退掉。**正确判据**：前景内残留品红占比 <0.1% 且叠底色目视无色环。
