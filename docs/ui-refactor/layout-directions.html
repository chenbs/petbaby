宠物主页 Pet-Centric Hub

D I R E C T I O N   F

杂志封面 Editorial Cover

刊物封面的表达方式：满版图 + 期数标识 + 巨大标题 + 一段引文 + 顶底细线框住版心。 它的质感不来自装饰，来自排版纪律 —— 大留白、极端字重对比（700 的黑体标题 配 300 的斜体）、精确负字距、一条 1px 的横线。整屏没有一个圆角卡片、没有一个阴影。

这是五个方向里信息量最低但气质最高的一个，适合做「一屏定调」的场景， 不适合承载列表和操作。

用户心智：阅读开篇　·　「这是什么」

抓眼球高 大字 + 满版图
可爱度低 冷静克制，反萌
质感最高 五向里最「高级」
成本低 结构极简，难在文案
硬依赖文案质量 —— 标题烂了整屏就垮
风险信息量极低，不能承载操作和列表
参考Kinfolk / NOWNESS / 单向街 / Apple Newsroom

为 什 么 显 得 高 级
「高级感」在技术上就是克制：
元素越少、留白越大、层级越靠字重而非颜色区分， 观感就越贵。

这一屏只有 5 个元素，但每个元素的位置和字距都是精确的 —— 这正是现有界面缺的东西。

即使不整屏采用这个方向， 它的排版方法论也值得全站吸收。
D I R E C T I O N   J

黏土软萌 Claymorphism / Soft 3D

「可爱就要极致可爱」的极端解，五个方向里唯一把可爱度拉满的。 核心不是配色，是体积感：超大圆角（28px+）、内高光 + 内阴影 + 双层外投影 模拟「捏出来的」厚度，按钮像果冻，按下应有 Q 弹回弹。

成本远低于看起来的样子 —— 黏土质感 100% 由 CSS 多层 box-shadow 实现， 不需要任何 3D 素材或图片。左边整屏除成品图外没有一张位图。

两点必须诚实说明：一，Claymorphism 的趋势材料明显偏薄，多为断言、缺实例； 二，它和「企业级质感」是反方向的 —— 可爱度拉满的代价就是专业感下降。

用户心智：玩具　·　「好可爱，想戳一下」

抓眼球很高 在扁平小程序里极显眼
可爱度最高 唯一拉满的
质感中 「玩具感」不是「企业级」
成本低 纯 CSS，零素材
硬依赖强依赖配色，唯一不能用中性色的方向
风险多层阴影低端安卓掉帧；
写实成品图与黏土 UI 可能割裂
参考Duolingo / Headspace / Bumble / Clay 3D

五向对照

本表只描述形态特征，不做页面分配。具体分配等读过项目代码后再定。
分类依据：一个方向是能支撑整个信息架构（骨架型），还是只适合注入特定场景（局部型）。
方向 类型 信息密度 最强的一点 最大的限制 形态特征
A 作品墙 骨架 中高 把结果放到最前 依赖样例图质量 图片为主的规整网格，1 大 + 2 列制造节奏；文字压图，遮罩承载可读性；可复用到几乎所有列表和详情场景。五向里通用性最强的一个。
C 沉浸流 局部 最低 一屏一个焦点 装不下列表和密集信息 满屏图 + 渐变遮罩 + 悬浮操作。同一模式可用于两类场景：整屏浏览（上下滑），或把浮层换成表单/面板（背景保持虚化目标图）。
E 宠物主页 骨架 中 情感联结最强 无数据时是空的 对象优先而非功能优先：封面 + 身份信息 + 统计 + 最近产出 + 可做的事。同一套架构可切换为时间轴形态用于叙事。唯一改变信息架构的方向。
F 杂志封面 局部 最低 气质最高 只能定调，不能承载操作 满版出血图 + 期数 + 巨大标题 + 引文 + 细线。无圆角、无阴影、无卡片。靠字重与字距建立层级。即使不整屏采用，排版方法论也应全站吸收。
J 黏土软萌 局部 中 可爱度唯一拉满 与「企业级」直接冲突 纯 CSS 体积感：超大圆角 + 内高光 + 内阴影 + 双层外投影。可整屏采用，也可只把质感注入到按钮、图标容器、结果卡片等局部。可爱与高级必须选一边。
