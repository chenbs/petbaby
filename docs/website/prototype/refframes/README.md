按叙事关键点抽了 **9 帧**。用途：

1. **编辑底图** —— `frame-05_5s.png`（猫脸最清晰 + 壁虎在正上方，全片信息最全）是改写用的
   主底图；若需空镜首帧则用 `frame-00_0s.png`。改图与生成提示词见
   [`../../01-KittyPaw复刻规格.md`](../../01-KittyPaw复刻规格.md) 第 8.3 节。
2. **动作参考** —— 走「全能参考」路线时，原 `bg.mp4` 直接作参考视频；这些帧用于核对节拍。
3. **构图比对** —— 自制视频出来后对照检查透视角度、植物疏密、留白位置。

> 注意：**这 9 帧不是拿来一次性全投进生成工具的。** 关键帧越多，各帧之间的主体一致性风险
> 越大（每张里的德文猫若长得不一样，成片会在帧之间变脸）。实际只需编辑 1–2 张。

## 一个容易搞反的点

**猫走在天窗玻璃的上面，我们从室内隔着玻璃仰视它。** 8.5s 那帧看到的是肚皮和四只压在玻璃
上的爪垫，7.0s 能看到爪垫摊平。壁虎同样在玻璃外侧上方，5.5s 是四肢张开悬空的姿态，是掠过
而非贴着爬。

按「猫在室内地面抬头看窗外」写提示词会让模型把猫放到玻璃**下方**，空间关系整个反掉。
