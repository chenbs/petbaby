## 1. 愿景与路径

**终局愿景**：宠物情感资产平台——帮宠物主人记录、表达、庆祝、纪念宠物的一生。

**路径判断**：一人公司不能直接建平台，但可以沿着一条每一步都自己赚钱的路走过去：

```
阶段1                阶段2                阶段3                阶段4
玩法工具   ──────→   玩法平台   ──────→   复购型产品  ──────→  情感资产平台
(壳+3个玩法上线)     (周更玩法+纪念线)     (会员/实体/年度报告)   (亲友共建/轻社区)
第1-6周              第7-16周             第4-6个月             第7-12个月
```

每个阶段的产出物都独立成立：哪怕永远停在阶段 2，它也是一门能赚钱的小生意。

**核心资产逻辑**：所有玩法都往同一个地方沉淀——宠物档案 + 照片库 + 支付用户。方向可以换、玩法可以死，账户体系和数据资产从第一天就是同一套，这是通向平台的暗线。

## 2. 阶段定义

### 阶段 1：壳 + 首发玩法上线（第 1-6 周）

- 产品目标：上线微信小程序 + H5，壳完整可用，首发 3 个零边际成本的排版类玩法（证件系列、电影海报、时光画册）。
- 运营目标（并行，见 operations/03）：小红书账号起号，用手工样品测款，积累首批种子用户。
- 交付清单：见 product/03-features-shell.md 的 P0 列表。
- **验收线（第 8 周末评估）**：
  - 累计付费 ≥ 50 单
  - 生成成功 → 付费转化 ≥ 3%
  - 至少 1 个玩法的笔记出现自然流量（单篇曝光 > 5,000）
- **止损条款**：付费转化 < 2% 且无任何玩法笔记跑出流量 → 暂停开发 4 周，全力做内容；内容仍无起色 → 触发方向复盘（换品类或收缩到纪念线单点）。

### 阶段 2：玩法平台化（第 7-16 周）

- 产品目标：
  - 玩法周更机制跑通（新玩法上架 ≤ 2 天）
  - 上线第一批 AI 生图类玩法（拟人化、职业写真，按次收费覆盖 API 成本）
  - 上线纪念产品线（粒子星尘页、纪念册），验证高客单
  - AI 短视频（FFmpeg 模板合成）
- **验收线（第 16 周末）**：
  - 月流水 ≥ 8,000 元且连续两月环比增长
  - 60 天内二次付费率 ≥ 15%
  - 纪念线客单价 ≥ 39 元且有真实成交
- **止损条款**：月流水 < 3,000 且无增长趋势 → 砍掉表现最差的一半玩法，收缩到 Top 2 玩法 + 纪念线。

### 阶段 3：复购与客单价（第 4-6 个月）

- 产品目标：
  - 纪念日订阅消息（生日/到家日召回）
  - 实体商品代发（画册、台历，按单生产，先手工履约 20 单）
  - 轻会员（复购数据支撑后再上线）
  - 年度铲屎官报告（年底传播节点，提前 1 个月备货）
- **验收线（第 6 个月末）**：月流水 ≥ 20,000 元（个人温饱线）。

### 阶段 4：平台雏形（第 7-12 个月）

前置条件：阶段 3 验收达标，且愿意加大投入（外包设计/招人）。

- 亲友共建空间（一只宠物带来多个用户）
- 作品广场（仅展示授权作品，评估审核成本后再定）
- 善终机构合作（纪念册分成，唯一的 B 端动作）
- 12 个月决策点：
  - 月流水 ≥ 50,000 → 向平台化扩展（社区、活动等）；v0.1 的平台路线图已从主文档树移除，需要历史背景请查 Git 历史
  - 20,000-50,000 → 维持一人模式深耕纪念利基
  - < 10,000 且无增长 → 产品转维护态，止损

## 3. 全局约束（所有阶段适用）

1. 任何新功能引入的**日常人工投入 > 每天 2 小时**即否决（客服、审核、运营均计入）。
2. 不做：公开 UGC 社区、同城活动系统、商家自由入驻、AI 伴聊、自研模型、自营库存。解禁条件：月流水 ≥ 50,000 且有专人负责。
3. 免费体验必须带水印/低清，付费前必须可预览。
4. 追思场景永远克制：不弹营销、不做排行、默认私密。

## 4. 北极星与核心指标

**北极星：月流水**（一人公司阶段不看 DAU/留存叙事）。

四个核心过程指标（每周一复盘，定义见 operations/01-ops-plan.md 第 5 节）：

1. 付费转化率（生成成功 → 付费）
2. 单 UV 收入 vs 单 UV 边际成本
3. 分享带新率（每个付费作品带来的新访问 UV）
4. 小红书周自然曝光量（获客先行指标）
