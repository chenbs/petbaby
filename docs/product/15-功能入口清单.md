## 用法

逐项测试时在「状态」列打标：`OK` / `问题` / `待改`。发现的功能缺口写进 `07-functional-backlog.md`，不要在本文件里堆待办说明。

本地起服务：`cd apps/platform && pnpm dev`（`localhost:3000`，`DATABASE_URL` 留空即落盘 PGlite，生成任务内联执行，不需要 `pnpm worker`）。小程序用开发者工具打开 `apps/miniprogram`，改样式后必须跑 `pnpm validate`。

注意两处本地放宽：非生产环境未登录会回落到固定 demo 用户，`isAdmin()` 直接返回 true。所以「本地能进后台」不代表线上权限正确，权限相关的项要按生产语义单独判断。

## 五、Worker 与定时动作

三条驱动路径：`pnpm worker` 生产循环、`internal/*` 路由手动触发、本地/E2E 在 `POST /api/generations` 内联执行（`DATABASE_URL` 为空或 `memory://` 时）。

`scripts/worker.ts` 每轮（默认 1 秒）并发跑图文生成、视频渲染、AI 任务；每 60 秒一轮运维动作：健康快照、关闭超时订单、清理过期内容、投递订阅消息、赠送冻干过期、纪念日提醒。两类按小时单独扫（各 `3_600_000` ms）：**「去年今日」**（遍历全部用户，一天最多产出一条消息）与**健康主动提示**（`runHealthReminders`，三类走站内通知）。

视频队列并发是 1，叙事年度视频是四段 filtergraph 一次 `spawn` —— 加重任务前先确认限流。

lingsuan 图片请求进入同一进程级 FIFO 队列，默认并发上限 20；网络错误、429 和 5xx 最多重试 3 次，不可恢复的其他 4xx 立即失败。单宠模板运行时按“冻结母版 → 宠物”传参，双主体模板按“冻结母版 → 主人 → 宠物”传参；宠物人化按“宠物原图 → 自有效果图”一次生成两张。缺参考图不得回落文生图。
