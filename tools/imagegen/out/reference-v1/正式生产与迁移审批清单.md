## 3. 正式提示词与生产输入

单一事实来源：`tools/imagegen/reference-template-prompts.mjs`。

固定生产规则：

1. 输入 1 只能是 `masters/index.json` 中登记的自有冻结母版。
2. 单宠输入 2 是当前用户宠物身份图；双主体输入 2 是授权主人身份图、输入 3 是当前用户宠物身份图。运行时不上传 `example/` 中的第三方效果图。
3. 使用 lingsuan `/v1/images/edits`，`quality=high`、`input_fidelity=high`。
4. 保留母版核心构图、场景类型、动作、服装、地标、独特道具和文字布局。
5. 冻结母版后的运行时迁移场景变更预算为 0%；只替换宠物身份，母版场景、构图、动作、表情、视线、服装、道具和文字布局保持不变。
6. 文字可按宠物和场景修改，但必须准确可读；服装可保持、换色或轻微调整。
7. 宠物保持身份图中的实际成年年龄和品种比例，不得幼化、放大头眼或缩短口鼻；同时不得瘦长、病态、老气、凶或怪异。
8. 竖版严格输出 720×1280，横版严格输出 1280×720；本地回读宽高和有效画面内容，不合格不得入库。

生产命令：

```powershell
node tools/imagegen/freeze-reference-masters.mjs
node tools/imagegen/approve-dual-subject-masters.mjs
node tools/imagegen/generate-reference-validation.mjs migrations
node tools/imagegen/audit-reference-outputs.mjs
```
