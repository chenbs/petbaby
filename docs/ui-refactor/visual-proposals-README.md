# 小程序整体美术风格方案

三套已选方向、逐页分配与待实施事项见 [`小程序美术方向确认与待实现清单.md`](./小程序美术方向确认与待实现清单.md)。本页保留七套原始候选供回看，其中官网参考预览的图片圆角已按确认意见调整。

## 打开方式

直接打开同目录的 [`visual-proposals.html`](./visual-proposals.html) 即可查看。图片使用现有官网样片的相对路径，建议从仓库根目录用静态服务器打开，避免浏览器对本地文件图片权限限制：

```powershell
npx --yes serve .
```

然后访问 `http://localhost:3000/docs/ui-refactor/visual-proposals.html`。
