# 写真扩容与横滑验收（2026-09-28）

## 实现范围

- 非写真 AI 模板、电影海报、时光画册和互动场景使用原生 `swiper`；滑动更新当前模板或效果，照片选择在同一页紧随其后。单效果玩法保留直接选照片的路径。
- AI 图片新任务与重抽统一生成 2 张候选；历史 4 张候选任务仍可读取、比较和选择。
- 写真新增 12 套，共 24 套。新样片金毛、泰迪、英短各 4 张；生成时用户上传的宠物照片仍是唯一宠物身份依据。

## 实际验证

- `apps/miniprogram`: `node scripts/build-sample-assets.js` 产出 118 张本地样片；`npm.cmd run validate` 通过 24 页结构、4 主题、57 token、66 条 Node 测试。
- `apps/platform`: TypeScript 检查、ESLint（0 错误）、写真/插件配置/候选数量相关 Vitest 通过。旧 12 场景配置自动升级到 24，人工改过的配置保留。
- 平台完整覆盖率测试：54 个文件，537 条通过、2 条跳过；移动浏览器 E2E 6 条通过，生产构建通过。官网静态构建通过。小程序内置 118 张样片合计约 1.16 MB。
- 微信开发者工具模拟器：写真首页及新增金毛/泰迪样片、AI 模板页、电影海报、时光画册、互动场景均实际截图；AI 模板触摸横滑后 `templateId` 从 `pet-wanted-poster` 更新为 `pet-expression-grid`；画册切换后主题更新为 `birthday`，照片区仍在当前页。
- 本地 AI 任务 `0c6fef59-69e8-45b8-992d-802ed8c9e4bd` 由本地 Provider 实际生成 2 张，模拟器候选页显示 2 张；选第 1 张后 `selectedId` 写入并进入确认页。此验证覆盖候选数量与后续状态流，**不代表真实供应商图像质量**。
- 新增写真「紫色芭蕾后台」在模拟器里选中样片与宠物照片后，实际提交任务 `be3eb02f-8b42-4f0d-bd87-3d6ba5d8cb92`；服务端记录 `options.scene=ballet-backstage`、`templateVersion=v04`，本地 Provider 产出 2 张候选，点击第 1 张后 `selectedId` 正确写入并进入确认页。
- 本地 API 对新增 `scene-railway-traveler` 和 `scene-ballet-backstage` 样片返回 200；`GET /api/plugins` 返回 24 套写真配置。
