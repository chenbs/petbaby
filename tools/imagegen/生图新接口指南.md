# 生图接口使用指南

你只需要记住两个接口：

- 文生图：`POST /v1/images/generations`
- 改图 / 图生图：`POST /v1/images/edits`

接口地址示例：

```text
https://lingsuan.top/v1/images/generations
https://lingsuan.top/v1/images/edits
```

请求时都要带上你的 API Key：

```text
Authorization: Bearer 你的APIKey
```

## 1. 文生图

文生图就是：你给一句描述，接口返回一张图片。

### 请求地址

```text
POST https://lingsuan.top/v1/images/generations
```

### 最简单示例

```bash
curl https://lingsuan.top/v1/images/generations \
  -H "Authorization: Bearer 你的APIKey" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只白色小猫坐在窗边，阳光照进来，写实风格",
    "size": "1024x1024"
  }'
```

### 返回结果

接口默认返回 `b64_json`，也就是图片的 base64 内容。

返回大概长这样：

```json
{
  "created": 1783007786,
  "data": [
    {
      "b64_json": "这里是一大段图片base64内容"
    }
  ]
}
```

前端或后端拿到 `b64_json` 后，把它当成图片保存即可。

如果你想在网页里直接显示，可以拼成：

```text
data:image/png;base64,这里放b64_json内容
```

## 2. 常用参数

### 必填参数

| 参数       | 说明      | 示例            |
| -------- | ------- | ------------- |
| `model`  | 固定用这个   | `gpt-image-2` |
| `prompt` | 你想生成什么图 | `一张国潮风海报`     |

### 可选参数

| 参数                | 说明   | 常用值                       |
| ----------------- | ---- | ------------------------- |
| `size`            | 图片尺寸 | `1024x1024`               |
| `quality`         | 图片质量 | `low` / `medium` / `high` |
| `output_format`   | 输出格式 | `png` / `jpeg` / `webp`   |
| `response_format` | 返回格式 | `b64_json` / `url`        |
| `background`      | 背景   | `auto` / `opaque`         |
| `n`               | 生成张数 | 建议先传 `1`                  |

建议新手先这样传：

```json
{
  "model": "gpt-image-2",
  "prompt": "你的图片描述",
  "size": "1024x1024",
  "quality": "low",
  "response_format": "b64_json"
}
```

## 3. 改图 / 图生图

改图就是：你提供一张原图，再告诉接口怎么修改。

### 请求地址

```text
POST https://lingsuan.top/v1/images/edits
```

### JSON 图片链接方式

如果你的图片已经有公网 URL，可以这样传：

```bash
curl https://lingsuan.top/v1/images/edits \
  -H "Authorization: Bearer 你的APIKey" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "把这张图改成国潮海报风格，保留主体",
    "images": [
      {
        "image_url": "https://example.com/input.png"
      }
    ],
    "size": "1024x1024",
    "quality": "low",
    "response_format": "b64_json"
  }'
```

### 上传本地图片方式

如果你要直接上传本地图片，用 multipart：

```bash
curl https://lingsuan.top/v1/images/edits \
  -H "Authorization: Bearer 你的APIKey" \
  -F "model=gpt-image-2" \
  -F "prompt=把这张图改成国潮海报风格，保留主体" \
  -F "image=@input.png" \
  -F "size=1024x1024" \
  -F "quality=low" \
  -F "response_format=b64_json"
```

如果要局部修改，可以再传一张遮罩图：

```bash
curl https://lingsuan.top/v1/images/edits \
  -H "Authorization: Bearer 你的APIKey" \
  -F "model=gpt-image-2" \
  -F "prompt=只修改遮罩区域，把衣服改成红色" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "size=1024x1024" \
  -F "response_format=b64_json"
```

## 4. 价格说明

当前生图分组按图片尺寸计费：

| 尺寸档位 | 价格   |
| ---- | ----:|
| 1K   | 0.07 |
| 2K   | 0.08 |
| 4K   | 0.10 |

一般用户建议先用 `1024x1024`，也就是 1K 档。

## 5. 注意事项

1. 生图可能比较慢，正常可能需要几十秒。
2. 客户端超时时间建议设置到 `120` 秒以上。
3. 代理站通常主要使用同步接口，不要调用 `/api/images/generations/jobs` 这类异步接口。
4. 返回的是 base64 图片，不是图片文件链接。
5. `gpt-image-2` 不建议拿去普通聊天接口使用，生图请走 `/v1/images/generations`。
6. 如果提示分组不支持生图，需要确认你的 API Key 是否属于支持生图的分组。

## 6. 最小可用请求

只要这一段能跑通，就说明你的 key 可以正常生图：

```bash
curl https://lingsuan.top/v1/images/generations \
  -H "Authorization: Bearer 你的APIKey" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一个红色圆形图标，白色背景，极简风格",
    "size": "1024x1024"
  }'
```
