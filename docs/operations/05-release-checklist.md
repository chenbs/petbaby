## 健康分诊线验收（红线项，做错的代价大于其他线）

十条红线全文见 `../product/16-竞品分析与产品复盘.md` 3.8。以下每条都必须实测，代码侧已有用例钉住但真实文案与观感需人工过：

- **`memorial` 宠物在健康线全部功能上被拒**：端上列表过滤 + 服务端 `HEALTH_UNAVAILABLE_MEMORIAL`，导出与 `recordCare` 写入侧同样拦。三类主动提示的 SQL 逐条带 `life_stage <> 'memorial'`。
- **不出现任何药物推荐**：`mentionsDrug` 是代码级后置过滤，命中即整段降级。抽查药名/类别/剂量/动作/中英混写的绕过尝试。
- **最低紧急度档也带升级条件**，不给「不用去医院」的确定结论。
- **紧急症状走关键词直通不进模型**，口语表述（「喘得厉害」「尿不出来」）必须命中。
- **用户可见文案不出现「诊断」「确诊」「治愈」「问诊」**：页面、推送、类目描述、官网、小程序简介全覆盖。免责声明由服务端下发、与结论同屏不折叠。
- **体重只陈述变化不做评价**：给「较上次 +10%（400 克）」，不给「偏胖」「正常范围」「BMI」。
- **健康档案 PDF 是就医准备材料不是体检报告**：免责声明在第一页顶部、带底衬、位于正文之前；不可分享（无 share_token 无公开路径）；不打 AI 标识。**中文字形需在真实容器/打印下确认不是方框。**
- **免疫记录的项目名由用户自填**，产品不给候选清单。
- 主动提示去重有效：疫苗续期、再次称重、跨季度后能再次提示（`subject_key` 带变化量）。

- 四套主题（`cute`/`glass`/`light`/`dark`）× 26 页走查截图集（含 `island` 分包 3 页 —— 岛的 HUD 走既有 token，但底板是岛专用的内容变量，两者都要看），无颜色错配与不可读文本。
- iOS 与 Android 真机各一台验证 `glass` 主题：`backdrop-filter` 生效表现，以及不支持时自动降级为不透明表面 + 更强描边。
- 玻璃面板三个档位在图片/视频两类作品上的表现，主 CTA 在三档均可见。
- 刘海屏与非刘海屏的导航栏走查；面板拖动帧率与「拖动期间零 `setData`」实测。

## 上线与回滚

- 部署前创建数据库备份；先部署迁移，再部署 Web 与 Worker；最后开放流量。
- 灰度检查登录、上传、生成、支付回调、下载、分享和退款各一单。
- 回滚只回滚应用镜像，不逆向删除兼容字段；必要时开启生成熔断并停止 Worker。
- 发布后 24 小时重点监控队列积压、生成失败率、单次成本、支付通知和媒体 404。

## 阶段二、三专项

- 普通 AI 模板返回四个候选并支持重抽；宠物人化返回两个候选且不支持重抽。两类任务的 AI 标识、成本记录、取消/失败恢复、选中结果和高清权益均正确。
- 图片货架已登记 9 个入口 / 116 个条目（76 live / 40 pending-review）；逐张验证全部 live 模板展示图返回 200 且尺寸正确、运行时参考图按注册键可读取。V2 人化图片、提示词与计划对象键的本地一致性门禁已通过；明确发布批准、对象上传和真实调用验证前继续保持 `pending-review`。旧方案中间图、主人身份原图和历史私有人形身份卡不得进入对象存储 seed。
- 双主体正式公开前至少用 12 位不同外观主人完成人工盲评；当前 4 位主人、80/80 生成成功只算工程稳定性，不算发布质量通过。
- 主人照片上传必须确认授权，列表、媒体读取和删除均校验归属；账户删除后原图对象和数据库记录均不可再访问。
- 用真实 lingsuan 验证单宠“母版 → 宠物”和双主体“母版 → 主人 → 宠物”顺序，缺参考图明确失败，定向重抽不改变未选角色和构图。
- 宠物人化用真实 lingsuan 验证输入顺序严格为“宠物原图图一 → 自有效果图图二”，一次只生成 2 张，成品均为完整自然真人；确认没有新增身份缓存/身份成本，端上不显示重抽入口，服务端重抽返回 409。效果图同一对象必须同时承担公开样图和图二，且用户明确审批前不得改为 `live`。
- 互动页的匿名访问、停留归因、撤销/过期和服务端 15 秒 MP4 导出完成预发布验证。
- 独立视频项目可保存/排序/编辑、生成预览、取消/重试、支付解锁、归档、下载和分享；FFmpeg Worker 失败不死循环。
- 纪念空间可隐藏/恢复，纪念册、纪念视频和星尘页可生成、归档、解锁、分享和撤销。
- 赛马后台可筛选指标、比较 live 基准、合法流转、回滚并保留操作历史；双端只展示同一 live 变体。
- 订阅消息按宠物授权，提前 7 天调度、频控、退订、失败重试和微信响应记录完成预发布验证。
- 实体 SKU/地址、支付退款、印刷 PDF/QC、物流和管理员人工履约完整演练一单。
- 月/年会员购买、额度发放/扣减/返还/重置、宽限期、续费失败和退款回收完成预发布验证。
- 年度报告生成、免费预览、订单/会员解锁、历史版本、下载、公开分享和撤销完整演练一份。
- 非管理员访问全部 `/admin/*` 和 `/api/admin/*` 返回 404；管理员可从正式导航进入驾驶舱、审计、用户、赛马、互动、视频、纪念和商业后台。
- 管理停用与主动注销互不混用；停用关闭公开分享，恢复不复活注销资产；全部人工操作可在统一审计中按原因追溯。
