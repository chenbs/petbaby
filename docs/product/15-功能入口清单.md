# 功能入口清单（Web / 后台 / REST / 玩法）

盘点自 2026-08-19 的工作区代码。本文回答「从哪进、打哪个接口」。

**与 [`21-小程序功能点清单.md`](21-小程序功能点清单.md) 的分工**：小程序侧的逐页功能点、状态列和「改一项要动哪几端」在 21 号文，本文不重复；本文维护 **Web/H5 页面、管理后台、REST 路由、玩法 manifest 和 Worker 轮次**。功能口径以 [`07-functional-backlog.md`](07-functional-backlog.md) 为准，UI 约定见 [`../ui-refactor/阶段0-代码盘点与方向分配.md`](../ui-refactor/阶段0-代码盘点与方向分配.md)。

规模快照：Web/H5 与后台页面 37 个（28 个前台 + 9 个后台）、REST 路由 132 个（含 `island` 9 条）、内置玩法 manifest 10 条（7 live + 3 archived 供历史作品解析）、图片货架已登记 9 个入口 / 116 个模板（76 个冻结、40 个 V2 人化模板待发布审核）；公开接口当前只返回含 live 模板的 8 个入口。小程序有 23 个主包页（清单见 21 号文）；漂移计数的权威值只看 `../README.md`。

## 用法

逐项测试时在「状态」列打标：`OK` / `问题` / `待改`。发现的功能缺口写进 `07-functional-backlog.md`，不要在本文件里堆待办说明。

本地起服务：`cd apps/platform && pnpm dev`（`localhost:3000`，`DATABASE_URL` 留空即落盘 PGlite，生成任务内联执行，不需要 `pnpm worker`）。小程序用开发者工具打开 `apps/miniprogram`，改样式后必须跑 `pnpm validate`。

注意两处本地放宽：非生产环境未登录会回落到固定 demo 用户，`isAdmin()` 直接返回 true。所以「本地能进后台」不代表线上权限正确，权限相关的项要按生产语义单独判断。

## 五、Worker 与定时动作

三条驱动路径：`pnpm worker` 生产循环、`internal/*` 路由手动触发、本地/E2E 在 `POST /api/generations` 内联执行（`DATABASE_URL` 为空或 `memory://` 时）。

`scripts/worker.ts` 每轮（默认 1 秒）并发跑图文生成、视频渲染、AI 任务；每 60 秒一轮运维动作：健康快照、关闭超时订单、清理过期内容、投递订阅消息、重置会员配额、下线逾期会员、纪念日提醒。两类按小时单独扫（各 `3_600_000` ms）：**「去年今日」**（遍历全部用户，一天最多产出一条消息）与**健康主动提示**（`runHealthReminders`，三类走站内通知）。

视频队列并发是 1，叙事年度视频是四段 filtergraph 一次 `spawn` —— 加重任务前先确认限流。

lingsuan 图片请求进入同一进程级 FIFO 队列，默认并发上限 20；网络错误、429 和 5xx 最多重试 3 次，不可恢复的其他 4xx 立即失败。单宠模板运行时按“冻结母版 → 宠物”传参，双主体模板按“冻结母版 → 主人 → 宠物”传参；宠物人化按“宠物原图 → 自有效果图”一次生成两张。缺参考图不得回落文生图。
