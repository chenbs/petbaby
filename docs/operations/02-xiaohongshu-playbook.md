# 小红书内容运营执行手册

版本：v3.0 ｜ 更新：2026-07-20
上游：operations/01-ops-plan.md ｜ 定位：唯一主渠道的完整执行手册，随经验持续沉淀

## 1. 账号定位

- **人设**：一个会做产品的铲屎官，"我给我家猫/狗做了个 XXX"——第一人称记录向，不是官方号口吻。
- **账号名方向**：贴人设不贴品牌（例：「XX 和它的猫」风格），品牌词放简介和水印。
- **简介要素**：养宠身份 + 在做的事（给宠物做好玩的东西）+ 小程序引导（合规方式：群聊/瞬间引导，不硬放外链）。
- **禁忌**：开号前 2 周不发任何带营销痕迹的内容，先养号（正常浏览、点赞宠物内容）。

## 2. 内容类型与配比

| 类型 | 说明 | 配比 | 作用 |
| --- | --- | --- | --- |
| 成品展示 | "给我家猫做了张身份证"，多图晒成品 | 40% | 测款主力，直接带私信 |
| 过程记录 | "为了给猫做画册我学了 XX"，做产品的过程 | 20% | 人设与信任，粘性最高 |
| 情绪叙事 | 宠物故事 + 成品（纪念线内容归此类，克制发） | 20% | 高转发高收藏，接高客单 |
| 互动/测试类 | "测测你家猫的 MBTI"、投票选下一个玩法 | 15% | 涨互动，收集需求 |
| 用户晒单 | 授权作品转发 + 用户故事 | 5%（后期增） | 社会证明 |

## 3. 单篇笔记 SOP

1. **选题**：来自当周赛马方向（弹药库 testing 项）+ 节日日历 + 评论区需求。
2. **封面**：成品图占满画面 + 大字标题贴纸；宠物脸必须清晰（封面决定 80% 点击）。
3. **标题公式**（择一）：
   - 悬念式："花了 3 小时，给我家猫办了个证"
   - 情绪式："它不会知道自己有多好看"
   - 教程式："手把手教你给狗子做电影海报"
4. **正文**：150-300 字，讲故事不讲功能；结尾一个互动问题（"你家主子叫什么？评论区报名"）。
5. **标签**：3-5 个：1 个大词（#宠物）+ 2 个精准词（#宠物写真 #猫咪日常）+ 1 个活动/节日词。
6. **发布时间**：工作日 12:00-13:00 或 19:00-22:00；周末 10:00-11:00。
7. **发布后 1 小时**：回复每条评论（前 1 小时互动权重最高）；私信咨询按话术模板接单。

## 4. 发布节奏

- 基准：**每周 3-5 篇**，其中 2-3 篇服务当周赛马方向，1-2 篇人设/互动内容。
- 断更红线：任何一周 ≥ 2 篇（产品再忙也要保住）。
- 存稿机制：每周日备好下周至少 2 篇的素材和文案。

## 5. 数据复盘方法（每周一，并入例行复盘）

按篇记录：曝光、点击率（阅读/曝光）、互动率（赞藏评/阅读）、私信数、成交数。

判断口径：

- 点击率 < 5% → 封面标题问题，同内容换封面重发一次。
- 点击率高但互动 < 3% → 内容不留人，正文结构问题。
- 互动高但私信少 → 缺行动引导，检查结尾 CTA 和评论区置顶。
- 单篇曝光 > 5,000（自然流量）→ 爆款候选：追加同系列 2 篇 + 评估投薯条（单篇 ≤ 200 元）+ 该方向进入赛马快车道。

## 6. 私信接单话术框架（手工测款期）

1. 咨询响应：感谢 + 确认宠物信息（名字/照片数量）+ 报价与交付时间（24h 内）。
2. 报价锚点：按弹药库定价报，不还价；犹豫者送"额外一张小图"而非降价。
3. 交付：成品 + "满意的话求个好评/晒单"；不满意按退款规则处理。
4. 沉淀：成交用户邀入老客户群；聊天记录里的需求关键词记入弹药库备注。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 限流/判营销 | 内容记录向包装；引流话术放私信不放正文；外链引导用合规方式 |
| 账号异常 | 备用账号同步养号（只养不发）；老客户微信群作为流量兜底资产 |
| 爆款被抄 | 无解也不慌：拼上新速度，抄袭者没有插件化的承接能力 |
| 纪念内容翻车 | 只发自己或授权用户的故事；评论区出现哀伤求助时私信回应并附专业资源，不公开消费 |
