## 当前问题判断

- 现有作品图大量使用木桌、胶带、纸张、相框等道具，画面信息多但品牌识别弱，容易像 AI 样片或电商素材。
- 同一页面同时出现暖木色、纸张米色、星空深蓝和高饱和橙色，图片之间缺少统一的色彩与裁切规则。
- 玩法区是三张 4:3 小卡，作品区又是缩略带加瀑布流，真正的成品细节被压小，用户难以感知产品质量。
- 两个详情区虽然有大图，但画面仍被“挂画/场景道具”包裹，产品本身没有成为唯一主角。

## 三个方向

### A｜编辑画廊

温暖的米白底，保留现有浅色品牌氛围，把核心作品改成 1 张主图 + 2 张辅助图。图片比例统一为 4:5 或 3:2，减少道具，让成品本身占画面 80% 以上。适合强调陪伴、纪念和内容质感。

### B｜品牌影棚（推荐）

以白底、墨色文字和少量玫红作为品牌系统，使用大面积留白、细边框和编号标签。首屏视频之后直接进入一张横向主视觉，再用两列大图展示玩法。视觉更像成熟的内容产品或设计工具，最适合“企业级”的目标。

### C｜沉浸影院

首屏视频结束后延续深色背景，用全宽作品图、低饱和色和大字号标题建立电影感。图片可以更大胆、更满，但信息密度最低，适合把品牌定位成高端纪念影像服务。

## 建议的落地顺序

1. 先选 A、B 或 C，确定背景色、图片比例和主图节奏。
2. 单独重做官网图片资产：每类玩法先产出 1 张主图、2 张辅助图，统一光线、镜头距离、色彩和留白，不在现有素材上继续修修补补。
3. 保留首屏视频、顶栏、现有区块顺序和 CTA 位置，只调整图片区块的占比、裁切、卡片密度与标题层级。
4. 先替换“核心玩法”和“作品展示”两段，确认大图阅读效果后，再同步两个详情区和移动端比例。
5. 最后做桌面 1440px、平板 768px、手机 390px 三档检查，确认大图没有遮挡标题、按钮或二维码入口。

## 选择时请重点看

- 你希望访客第一感受更接近“温暖的内容品牌”（A）、“成熟的产品品牌”（B），还是“高端影像品牌”（C）。
- 作品图是更偏真实生活照片，还是更偏成品海报、画册、肖像等设计结果。
- 是否接受作品区使用深色背景；这会显著改变后续页面的阅读节奏。

示意图中的图片只是现有资产占位，最终图片需要按选定方向重新拍摄或生成，不代表最终素材质量。
