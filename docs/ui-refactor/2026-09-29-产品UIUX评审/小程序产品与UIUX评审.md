## 1. 结论摘要

1. **能力齐全，表达混乱。** 服务端已经有写真、110 多个模板、40 款人类转生、电影海报、画册、短片、互动页、趣测、时间线和健康。首页却把它们平铺成 11 个同级区块。两个运营重点（麻麻精选、人类转生计划）分别排在第 3、4 位，首屏看不到。
2. **有功能「上线了但找不到」。** 互动星尘页（PL-15）在小程序里已经没有入口，但页面、接口和后台代码都还在，这次一并下线。短片草稿、制作中的写真和人化任务，离开后都找不回来。
3. **品牌气质偏冷，四套主题只是换色。** 默认主题是白底、薄荷面、墨绿字。四套主题的圆角、阴影、字体、动效、布局几乎完全相同，底栏的主题样式类名已经失效。
4. **最大的转化漏洞在「做完之后」。** 等待约 1 分钟，页面却写「完成后在作品柜查看」，但作品柜不读这类任务。分享卡好友大概率打不开。趣测海报是纯文字。
5. **改版方向**：
   - 默认主题换成橘子汽水，另外三套各自形成独立的设计语言。
   - 首页压缩为「宠物名片 → 人类转生计划 → 麻麻精选 → 分类瀑布流」。
   - 底栏改为五格：首页、创作、＋记录、作品、我的。
   - 打通「等待 → 提醒 → 统一作品柜 → 公开分享页」。
   - 去掉宣传文案里的 AI 字样和全部水印；生成结果只在小程序界面上加底部蒙层「该内容由AI生成」；付费点只保留「保存高清原图」一项。

麻麻精选是**品牌语气的编辑推荐位**（「麻麻」就是用户本人的昵称视角），不是一个分类。它跨分类挑出当周最好玩的内容，用来告诉新用户「从这里开始就对了」。

| 位置 | 展示 |

## 5. 视觉方向：橘子汽水（默认主题）

效果见 [`shots/section-board.png`](./shots/section-board.png)。核心原则：**照片是主角，暖色衬底，墨色压字，一个主色加两个点缀色**。莓果色方案作废。

### 5.1 三个备选配色

| 方案 | 色板 | 气质 | 判断 |
| --- | --- | --- | --- |
| **A 橘子汽水（已采纳）** | 奶油 `#FFFAF3`、杏 `#FFF1E0`、浅橘子 `#FF9A52`、焦橘 `#B7401A`、奶黄 `#FFD45C`、钴蓝 `#2A5FE8`、墨蓝 `#1F2540` | 阳光、零食、晒太阳，年轻有活力 | 和宠物常见毛色（橘、黄、棕、白）都协调，适合「晒」。按钮调浅一档后更像汽水，也不那么像促销 |
| B 蓝莓酸奶（未采纳，留档） | `#F7FAFF`、`#2356D6`、`#FFD45C`、`#FF9FC0`、`#1B2440` | 干净、潮、像年轻潮牌 | 辨识度高，温暖感偏弱 |
| C 蜜桃乌龙（未采纳，留档） | `#FBF6EF`、`#FFB36B`、`#9A4A1C`、`#4F6B2C`、`#2B211C` | 柔和、治愈 | 最贴近「陪伴」，趣味性最弱；适合作为手账相册主题的基础 |

### 5.2 橘子汽水 token（在现有 `TOKEN_SPEC` 键名内调整 `pet` 主题取值）

对比度按 WCAG 公式用 node 计算。

| token | 当前 | 建议 | 对比度 |
| --- | --- | --- | --- |
| `background` | `#FFFFFF` | `#FFFAF3` 奶油 | 墨蓝字 14.48 |
| `surface` | `#F1F8F5` 薄荷 | `#FFF1E0` 杏 | 次级字 5.52 |
| `cardBackground` | `#FFFFFF` | `#FFFFFF` | 卡片从奶油底上浮起 |
| `textPrimary` | `#23312D` | `#1F2540` 墨蓝 | 14.48 / 白卡 15.03 |
| `textSecondary` | `#566B64` | `#5B6178` | 5.90 |
| `primary`（文字强调、选中、描边） | `#C52D53` | `#B7401A` 焦橘 | 奶油底 5.38 |
| `buttonPrimary` / `buttonPrimaryText` | `#C52D53` / 白 | `#FF9A52` 浅橘子 / `#1F2540` 墨蓝 | 7.16 |
| `secondary` | `#14776B` | `#2A5FE8` 钴蓝 | 白字 5.38 |
| 贴纸色（skin 层） | — | 奶黄 `#FFD45C`、天空 `#CFE6FF`、薄荷 `#BDEBCB` | 都配墨蓝字，≥ 10.6 |
| `border` / `divider` | `#D3E4DC` / `#E4EEE9` | `#F3E3D2` / `#F6ECE0` | 暖色细线 |
| `success` / `warning` / `error` | 保留语义 | `#23794A` / `#A15A00` / `#C0352B` | 都 ≥ 5.0 |

- **按钮用深字不用白字**：浅橘子底配白字只有 2.10:1，不可读；配墨蓝字是 7.16:1，看起来也更像贴纸，这是这套配色年轻感的来源。
- **浅橘只做底色，不做文字和细线**：`#FF9A52` 在白底上只有 2.10:1。所以价格、选中描边、天数、链接等文字性强调，一律用焦橘 `#B7401A`（5.38:1）。按钮上的勾、进度节点等图标也用墨蓝，不用白色。
- `app.wxss` 的 `page{}` 兜底值要同步（validate 第 8 项会比对）。暖褐色阴影 `SHADOW_HUE` 不用改。
- **官网现在是莓果色**，而且 `site.css` 是原型的逐字节副本。小程序换色后，两边会暂时不一致。官网是否同步换色需要单独决定。

### 5.3 字体、图标与组件

- **字体**：标题字重 800，靠字重而不是字号拉开层级；数字（天数、张数、已选 10/10）统一用 44rpx / 800。辅助文字统一用 `#5B6178`，不出现低于 4.5:1 的浅灰。
- **图标**：用一套 24px、1.8 描边、圆头的线性图标替换所有 Unicode 字形。底栏用 `<image>` 加载 @2x/@3x PNG，选中态用实心加主色。首页导航左侧放爪印 logo 加「麻麻抱我」字标。
- **按钮**：每屏只有一个实心主按钮；次级按钮用杏色胶囊；禁用状态的按钮文字写明原因（例如「请先选照片」）。
- **标签**：免费用奶黄，新用天空蓝，热门和待保存用浅橘，已完成用薄荷，麻麻精选用奶黄贴纸。标签里不出现「AI」。
- **AI 提示蒙层**：凡是展示 AI 生成结果的地方（挑选页、作品详情、作品柜缩略图、写真成片、分享落地页），都在图片容器底部叠一条深色渐变蒙层，写白字「该内容由AI生成」。蒙层是界面元素，不写进图片文件；四套主题样式统一，不跟主题变色。排版类（证件、画册、成长对比）和视频模板不是生成内容，不加蒙层。详见 5.4 节和专项方案第 3 节。
- **卡片**：入口卡统一 3:4、`aspectFill` 顶部对齐，文字在图下方。作品详情和挑选页保持原比例完整显示。
- **固定底栏**：凡是有「选择 → 下一步」的页面，都用「已选数量 + 总价 + 主按钮」。

另外三套主题（手账相册、赛博街机、星夜影院）的设计语言，见[主题系统重设计方案](./主题系统重设计方案.md)和 [`themes.html`](./themes.html)。

### 5.4 付费点：只保留「保存高清原图」

去掉水印以后，需要重新定义付费买的是什么。结论是**只保留一个付费点**，不另外包装「长期保存」「导出」等名目。

| 决定 | 理由 |
| --- | --- |
| 保留付费解锁，不改成全免费 | 写真和人化每次要调一次 lingsuan，单张 46–62 秒，有真实成本。每天 1 次免费额度只包括「制作 + 预览」 |
| 付费买的是「高清原图」，一项 | 用户能理解，也容易写在按钮上（「保存高清原图 ¥16.9」）。画册的 PDF、短片的 MP4 本来就是该玩法的原图形态，一起给，不单独收费 |
| 不单独卖「长期保存」 | 长期保存是所有作品的默认能力，不是付费权益。付费只决定能不能把高清原图保存到相册 |
| 作品永久保存，不再清理 | 这是 09-30 第三轮的决定。现在的 `cleanupExpiredContent`（`maintenance.ts:13-22`）会把 `locked=true` 且 `expires_at` 已过（生成后 90 天）的作品**连同文件和数据库记录一起硬删除**。这等于用户做过的东西，不付费就会消失，和「陪伴与记录」的定位冲突。改为：所有作品（含未付费预览）都长期保存，只有用户自己删除或注销账户时才清理。具体见专项方案第 3.6 节 |
| 预览和原图的区别 | 预览在小程序里可以看、可以放大、可以分享卡片，但不能长按保存。AI 预览维持长边 640px，排版类预览长边 1080px；原图是完整分辨率 |
| 免费玩法（证件、成长对比）照旧免费 | 直接给干净原图，可以保存 |
| 会员 | 会员权益改写为可数的「每月 N 张高清原图」，年度报告高清版保持不变 |

### 6.3 制作 → 等待 → 挑选（P0 / P1）

对照：[`shots/section-flow.png`](./shots/section-flow.png)。

- **制作页**：大图预览（标注「示例效果」）；横向缩略图切换同类效果；宠物用头像 chip 选择；照片区首格是「拍照 / 相册」，默认预选最近一张；下方一条拍摄建议。固定栏：「拍 2 张给我挑 · 免费预览 · 满意再保存 ¥x」。
- **等待页**：模糊的效果图做底，宠物头像居中；三段进度（认出你的宠物 → 换上布景 → 精修细节）；剩余时间按真实统计给出；「好了提醒我」申请一次性订阅；写明「离开也会继续做，在作品 › 进行中能找到」；下方推荐同类玩法。
- **挑选页**：两张并排，选中的放大并加勾；长按查看原图；主按钮直接写「保存高清原图 ¥16.9」，次按钮是「发给朋友看」。重抽降级为一行文字链接（人类转生不显示）。
  - 图片本身不叠角标或水印，只在界面上加「该内容由AI生成」底部蒙层。
  - 预览不能长按保存：放大查看用自定义查看器，不用 `wx.previewImage`。后者自带长按保存，也没法叠蒙层。
  - 去掉原方案里的「保存预览」按钮，保存就等于付费拿原图。
- 普通制作（`pages/create`）的等待和结果页使用同一套模式。

### 6.6 分享物（P0）

## 9. 实施顺序建议

1. **第一批（合规与闭环，约 1.5 周）**
   - 定下 AI 标识的合规方案。
   - 去 AI 文案、取消水印、加小程序内 AI 蒙层、调整付费标签。
   - 制作任务列表与进行中、完成通知。
   - 公开分享页和趣测海报。
   - 下线互动星尘页，修复短片下载校验。
   - 更新 CLAUDE.md。
2. **第二批（首屏与结构，约 1.5 周）**
   - 首页重排，纳入人类转生计划与麻麻精选。
   - 底栏五格，写真并入创作。
   - 写真定价与预选。
   - 人类转生直达造型、起名与筛选。
   - 麻麻精选配置化。
3. **第三批（品牌与主题，约 2.5 周）**
   - 橘子汽水默认主题、skin 基础设施与图标。
   - 其余三套主题分批上线。
   - 样片选角与重新裁切。
4. **第四批（细节，约 1 周）**
   - 我的、作品柜、时间线、档案、健康等页面按新规范整理。

每一批完成后都要：
- 跑 `apps/miniprogram` 的 `pnpm validate`，以及平台的 `pnpm check`。
- 在开发者工具里做 320 / 375 / 430px 截图。
- 做一次真机扫码，重点验证分享落地页、订阅消息、主题切换和安卓字体回落。
