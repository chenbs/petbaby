# 技术选型、成本与合规

版本：v3.2 ｜ 更新：2026-08-04
上游：product/02-product-design.md ｜ 原则：为一人维护优化，不为规模优化

## 1. 技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 小程序端 | 微信原生小程序 | 微信分享、支付闭环与较低运行时复杂度 |
| Web/H5/后台 | Next.js 16 App Router + React 19 | 页面、匿名分享、API 与后台同一部署单元 |
| 后端 | 严格 TypeScript 模块化单体 + 独立 Worker | 不上微服务/K8s，HTTP 与异步任务分离 |
| 数据库 | 生产 PostgreSQL 17；本地 PGlite | 同一套向前迁移，发布前必须完成 PostgreSQL E2E。运行时全部是原始参数化 SQL，drizzle 只用来生成迁移 |
| 官网 | Astro 7 静态站，独立域名 | 与应用互不影响；发布切软链原子生效，不碰 Docker、不跑迁移 |
| 存储 | 本地私有目录 / S3 兼容 OSS、COS | 生产 Bucket 默认私有，业务表只保存对象键和元数据 |
| 作品文案 | 当前使用确定性模板文案，可由用户编辑 | 不依赖未交付的 LLM；未来接入时必须放在可替换适配器后 |
| 排版渲染 | SVG + Sharp；PDF 使用 pdf-lib | 无浏览器渲染依赖，生成物可直接持久化与测试 |
| 生图 | 通用 HTTP Image Provider，主备两路 | 模型版本、成本和失败切换均保存快照，不自建模型 |
| 视频 | 服务端 FFmpeg 模板合成 | 不用生成式视频模型 |
| 任务调度 | 数据库任务表轮询 | 早期无并发压力 |
| 监控 | 健康检查、结构化日志、Webhook 与云监控 | 覆盖数据库、队列积压、失败率和成本熔断 |

架构关键词：**壳稳定、插件热更**——玩法通过配置+模板上架，不发小程序版本（见 03-features-shell F4）。

## 2. 成本防守

- 图片客户端压缩后存储；高清/原图仅付费后生成。
- 免费额度每天 1 次；image-api 全站日总额度封顶 + 成本熔断。
- 生成任务排队 + 同 openid 限频，防恶意刷接口。
- 实体商品一律按单代发，零库存。

## 4. 合规清单（第 1 周启动，流程比开发慢）

| 事项 | 说明 | 耗时 |
| --- | --- | --- |
| 个体工商户注册 | 微信支付与小程序认证前提 | 1-2 周 |
| ICP 备案 | 服务器备案，与开发并行 | 2-3 周 |
| 小程序类目 | 工具-图片处理；避开社交/社区类目 | 随审核 |
| 隐私政策/用户协议 | 明示照片用途、AI 标注、账号与数据可删除、数据可导出 | 1 天 |
| AI 生成标识 | 生图按《人工智能生成合成内容标识办法》（2025-09-01 施行）标注 | **已实现** `server/media/ai-label.ts` |
| 人脸相关（PL-14） | 主人合照类玩法上线前单独评估合成内容合规，取得用户明示同意 | 上线前（PL-14 仍是 idea） |
| 内容安全 | 用户可见文案过敏感词自检；无公开 UGC 则无社区审核义务 | 设计期内置 |
| **健康线文案法律意见** | 分诊定位、免责声明、四档紧急度与档案 PDF 的用户可见文案 | **待专业审查，是对外上线的产品性阻塞** |

**AI 标识的两条实现约束**（与营销水印命运相反）：付费也必须保留（第四条要求导出文件也带）；只对 `generator.type === "image-api"` 打标 —— 排版类是 SVG 套用户原照片、视频是 ffmpeg 模板合成，都不是生成合成内容。标识必须有深色底衬（白字压在白猫/雪地上等于没有标识，而「显著」是法条用词）。

### 4.1 健康线的合规边界（做分诊不做诊断）

《动物诊疗机构管理办法》第十八条要求线上诊疗必须由持《动物诊疗许可证》机构的备案执业兽医师开展，第六条又要求固定实体场所 —— **纯线上拿不到许可证**。微信「宠物医院」类目同样要这张证。所以定位只能是「症状记录 + 紧急度分级 + 就医准备」。

三条在代码里有强制点：不推荐任何药物（`mentionsDrug` 是代码级后置过滤，不能只靠提示词——用药剂量与禁忌高度依赖体重品种，猫对乙酰氨基酚致死）；不给「不用去医院」的确定结论（最低档也带升级条件）；`memorial` 宠物屏蔽全部健康功能（端上与服务端两处都要）。用户可见文案不得出现「诊断」「确诊」「治愈」「问诊」，覆盖页面、推送、类目描述、官网与小程序简介。十条红线全文见 `16-竞品分析与产品复盘.md` 3.8。

红线：不做医疗建议与诊断；哀伤支持内容不替代心理咨询，涉及危机提供专业求助渠道链接；未成年人内容谨慎处理。**「变化」不是「异常」** —— 体重只做减法陈述，不给「偏胖」「正常范围」「BMI」，体况评分是执业兽医的触诊项目。

## 5. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 大厂上同类功能 | 不拼 AI 能力，拼玩法上新速度 + 模板审美 + 纪念利基 |
| 生图"不像"投诉 | 4 选 1 + 付费前预览 + 排版类照片原样使用 |
| API 涨价/停服 | 生图选 2 家互备；LLM 提示词与供应商解耦 |
| 低端机互动页卡顿 | 粒子数按设备降级；提供静态兜底版 |
| 个人精力 | 每阶段止损线严格执行（见 roadmap）；系统可停服一周不出事故 |
